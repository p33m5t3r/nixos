
### setup
1. make this repo the source of truth `sudo ln -s nixos /etc/nixos`
2. symlink dotfiles to `~/.config`, e.g. `sudo ln -s nixos/.config/nvim ~/.config/nvim`
3. start the WM (optional) `THEME=whichever-theme start-hyprland`
